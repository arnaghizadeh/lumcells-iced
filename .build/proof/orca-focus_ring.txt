What this shows
- The window is a frame with its title; the check box, the toggler (a "toggle button" to
  Orca), the radio buttons, the pick list ("combo box", named by its chosen option), the
  buttons and the text input (an "entry", named by its placeholder) are announced with role,
  name and state when they get the focus, and state changes (checked, pressed, selected) are
  announced when Space changes them.
- The first Tab, from the frame to the text input, was not announced: Orca adopted the new
  focus while it handled the key itself (its log says "Switching object of interest from
  [frame: 'Focus ring'] to [entry: 'Your name']") and then found nothing new to say. Coming
  back to the same field with Shift+Tab it said "Your name entry.".
- Not announced: the option chosen with the Down key in the closed pick list (its name
  changes, Orca says nothing), and what is typed in the text input beyond the key echo (no
  text interface with caret and selection yet).
